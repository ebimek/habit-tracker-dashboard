\# HabitFlow - Interactive Habit-Tracking Dashboard  An interactive, zero-dependency web application for logging daily goals, visualizing weekly completion rates, and tracking long-term habit streaks.  ### [Live Demo](https://ebimek.github.io/habit-tracker-dashboard/)  ---  ## Key Features - **Weekly Check-In Matrix:** Log daily habit completions from Monday to Sunday with one click. - **Category Filtering:** Organize habits by Coding, Academic, Fitness, Reading, and Mindfulness. - **Real-Time Analytics & Streak Chart:** Interactive Bar and Area Curve charts powered by Chart.js. - **Streak Leaderboard:** Tracks current active streaks against all-time personal bests. - **Local Persistence:** Automatically saves all habits and check-ins in browser localStorage.  ## Built With - HTML5 & Vanilla JavaScript (ES6+) - Tailwind CSS - Chart.js - Lucide Icons  ## Running Locally 1. Clone the repository: `git clone https://github.com/ebimek/habit-tracker-dashboard.git` 2. Open `index.html` in any modern web browser.
