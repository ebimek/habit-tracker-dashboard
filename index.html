HabitFlow Dashboard — Built as a portable, single-file web application ready for GitHub Pages.

•

Create New Habit

Publish Dashboard to GitHub Pages

Deploy this self-contained dashboard to your own live `.github.io` URL in 60 seconds.

Step 1 • Export Single-File App

Download `index.html` with your current habits

Bundles your current habits and logs directly into the file so your live site starts pre-loaded.

Step 2 • Run in PowerShell / Terminal (inside the folder with `index.html`) 
# 1. Initialize Git repository in your folder containing index.html
git init
git branch -M main
git add index.html
git commit -m "Deploy HabitFlow interactive dashboard"

# 2. Link to your GitHub repo and push
git remote add origin https://github.com/ebimek/habit-tracker-dashboard.git
git push -u origin main
Step 3 • Activate GitHub Pages: In your GitHub repository, go to Settings → Pages, set Source to Deploy from a branch, select main branch (`/(root)`), and click Save. Your dashboard will be live at https://ebimek.github.io/habit-tracker-dashboard/

Your habits and daily streak logs are saved automatically in your browser's localStorage. Copy or download the JSON below to back up or migrate devices.
